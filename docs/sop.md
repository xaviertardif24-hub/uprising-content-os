00_INBOX_DROP
Use for: fast dumping from phone/camera/VA/editor.
No organization required
Everything lands here first
Rule: This folder should be “dirty.” Stuff gets sorted out weekly.
01_SW_Content
Use for: Student Works raw footage
coaching clips, training clips, jobsite moments, sales content, operator wins
02_SEPARATION_SUNDAY
Use for: Separation Sunday raw footage
runs, events, community clips, DJ/music, BTS, workouts
03_LIFE
Use for: personal lifestyle content
travel, day-in-the-life, routines, behind the scenes, relationship moments (clean)
04_Testimonials
Use for: raw testimonial videos + social proof
client/operator testimonials, before/after, screenshots exported as video/image
05_Pictures
Use for: still photos (non-video)
headshots, travel photos, brand photos, thumbnails source photos
06_PODCASTS
Use for: podcast raw
full recordings, raw audio/video, guest clips
07_Public Speaking
Use for: speaking events raw footage
keynote recordings, crowd shots, BTS, mic clips
08_Retreats

travel + event footage specific to retreats
Rule for RAW: If it’s unedited camera/phone footage → it stays in 00_RAW_CONTENT forever (raw is your “negative” / master).

01_EDITED_CONTENT (Work-in-progress edits)
Purpose: Drafts, versions, and edits in progress.
Put here:
Editor working exports (v1, v2, v3)
Project files (CapCut/Premiere exports if you store them)
Draft cutdowns not approved yet
Rule: Not final = not in Ready_to_Post.

02_READY_TO_POST (Final approved exports)
Purpose: Only the final files that can be posted today.
Put here:
Final MP4s (vertical 9:16)
Final thumbnails (if needed)
Optional: caption text file / notes
Rule: Everything here should be “postable with zero work.”

03_PUBLISHED (Proof + record)
Purpose: Archive of what actually went live.
Put here:
Final posted version (optional, but good)
Screenshot of post / thumbnail
OR a “Published Log” doc with links (recommended)
Rule: This is your “done” library.

99_ARCHIVE (Old / inactive / storage)
Purpose: Stuff you don’t use weekly.
Put here:
old campaigns, old edits, retired templates, past years, random leftovers
Rule: If it’s not actively part of the current machine → archive it.

Recommended workflow (how files should move)
Capture/upload → 00_RAW_CONTENT/00_INBOX_DROP
Sort weekly → move into the right RAW category folder (SW / SS / LIFE / etc.)
Editor pulls RAW → exports drafts into 01_EDITED_CONTENT
Once approved → final export goes to 02_READY_TO_POST
After posting → move/copy to 03_PUBLISHED + store post link
Old stuff / will not use→ 99_ARCHIVE
