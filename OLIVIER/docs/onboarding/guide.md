# Guide Onboarding Client — Antigravité

Ce guide regroupe toutes les étapes pour intégrer un nouveau client, ainsi que le **Stack IA gratuit** utilisé dans chaque phase du projet.

---

## ✅ Checklist Quickstart
1. [ ] Contrat signé + Acompte reçu
2. [ ] Dossier Drive créé (structure standard)
3. [ ] Mail de Bienvenue envoyé
4. [ ] Questionnaire envoyé (Tally/Typeform)
5. [ ] Appel de Kickoff planifié
6. [ ] Espace Notion client configuré → [notion-setup.md](./notion-setup.md)
7. [ ] Accès outils partagés (Framer, Notion, Drive)

---

## 🔄 Workflow Type — Nouveau Client

```
Proposition          Onboarding           Livraison            Suivi
(Claude + Gamma)  →  (Make + Drive)   →  (Cursor + v0)   →  (NotebookLM + Claude)
```

1. **Proposition** : Claude rédige le proposal, Gamma génère la présentation PDF.
2. **Onboarding** : Make crée automatiquement le dossier Drive + envoie le mail de bienvenue.
3. **Livraison** : Cursor + v0 pour coder et déployer le site Framer.
4. **Suivi** : NotebookLM comme base de savoir client, Claude pour les communications.

---

> [!TIP]
> **Par où commencer ?** Lance Claude pour rédiger ton premier proposal, puis Gamma pour le transformer en présentation. C'est le combo le plus rapide pour convertir un prospect.
