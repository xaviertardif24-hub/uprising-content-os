## 🧩 1. L'Écosystème CMS
Le CMS (Content Management System) est le cœur de votre site. Il sépare le contenu du design.

### 🔌 Accès Rapide
1.  Connectez-vous sur [Framer.com](https://framer.com).
2.  Ouvrez le projet **"Antigravité - Production"**.
3.  Cliquez sur l'onglet **CMS** dans la barre latérale gauche.

---

## ✍️ 2. Création de Contenu (Processus Pro)

### Étape 1 : Préparation
Avant d'ajouter un item, assurez-vous d'avoir vos textes prêts et vos images optimisées.

### Étape 2 : Remplissage des Champs
| Champ | Recommandation "Premium" |
| :--- | :--- |
| **Title** | Court, percutant et optimisé pour le SEO. |
| **Cover Image** | Image de haute qualité, format WebP (max 200Ko). |
| **Excerpt** | Le "hook" ! Doit donner envie de lire la suite. |
| **Content** | Utilisez des titres (H2/H3) et des citations pour aérer le texte. |

### Étape 3 : Organisation des Collections
*   **Catégories** : Utilisez des tags cohérents pour le filtrage automatique.
*   **Status** : Utilisez le champ status (si présent) pour programmer vos publications.

### Étape 4 : Validation & Publication
> [!IMPORTANT]
> Cliquez sur **"Save"** pour enregistrer en base, puis sur **"Publish"** (en haut à droite de l'éditeur principal) pour mettre en ligne.

---

## 📸 3. Guide de l'Image Parfaite
Pour garder un site rapide et élégant :
*   **Compression** : Utilisez [TinyPNG](https://tinypng.com).
*   **Ratio** : Respectez le ratio 16:9 pour les couvertures.
*   **Alt Text** : Remplissez toujours le texte alternatif pour l'accessibilité.

---

## ❓ 4. Résolution de Problèmes (FAQ)

**Q : Mes modifs ne sont pas en ligne.**  
R : Vérifiez si le bouton "Publish" est redevenu bleu. Une sauvegarde CMS ne suffit pas.

**Q : Le texte dépasse du cadre.**  
R : Limitez le nombre de caractères dans les titres pour éviter de briser le layout.
