# 📘 Guide Utilisateur : Gestion du CMS Framer

Bienvenue dans votre interface de gestion de contenu. Ce guide vous explique comment gérer vos articles et pages en toute autonomie.

## 1. Accéder au CMS
1. Connectez-vous à votre projet sur [Framer.com](https://framer.com).
2. Cliquez sur l'icône **CMS** (icône de pile de feuilles) dans la barre latérale gauche.
3. Sélectionnez la collection **"Articles"**.

## 2. Ajouter un Article
- Cliquez sur le bouton **"+ New Item"** en haut à droite.
- Remplissez les champs (Titre, Contenu, Image).
- **Astuce SEO** : Assurez-vous que votre mot-clé principal apparaît dans le titre et le premier paragraphe.

## 3. Utiliser l'Automatisation Aethera
- Les articles générés par l'IA apparaissent automatiquement avec le statut **"Draft"**.
- Vérifiez l' **"Aethera Score"** : un score élevé indique une excellente optimisation SEO.
- Relisez le contenu et cliquez sur **"Save"**.

## 4. Publier les Changements
> [!IMPORTANT]
> Les modifications dans le CMS ne sont pas visibles sur le site tant que vous n'avez pas publié le projet.

1. Cliquez sur le bouton bleu **"Publish"** en haut à droite de l'éditeur Framer.
2. Attendez la confirmation : "Site published".
