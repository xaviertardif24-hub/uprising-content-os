# 🎨 Brand Book - Olivier x Antigravité

Ce document définit l'identité visuelle et le ton de voix pour garantir une cohérence parfaite sur toutes les plateformes (Framer, Documents, Social Media).

## 1. Palette de Couleurs (Premium & Moderne)

Nous avons choisi une palette contrastée **Slate & Indigo** pour un rendu professionnel et technologique.

| Rôle | Couleur | Hex Code | Aperçu (Simulé) |
| :--- | :--- | :--- | :--- |
| **Primaire** | Indigo | `#4F46E5` | (Profond, Éclatant) |
| **Accent** | Violet | `#8B5CF6` | (Énergie, Action) |
| **Surface (Dark Mode)** | Slate 900 | `#0F172A` | (Fond sombre, élégant) |
| **Card (Dark Mode)** | Slate 800 | `#1E293B` | (Conteneur, Profondeur) |
| **Texte (Light)** | Slate 100 | `#F1F5F9` | (Lecture aisée) |
| **Texte Muted** | Slate 400 | `#94A3B8` | (Détails secondaires) |

## 2. Typographie (Google Fonts)

Des polices optimisées pour la lecture écran et le design Framer.

### **En-têtes : Outfit**
-   **Style** : Geometric Sans-serif.
-   **Impact** : Moderne, ouvert, premium.
-   **Utilisation** : Titres H1, H2, H3.

### **Corps de texte : Inter**
-   **Style** : Dynamic Sans-serif.
-   **Impact** : Clarté absolue, très lisible en petits formats.
-   **Utilisation** : Paragraphes, listes, boutons.

---

## 3. Ton de Voix

L'identité d'Olivier doit se refléter dans la rédaction des documents et des articles de blog :

1.  **Expert** : Maîtrise des sujets techniques sans être arrogant.
2.  **Accessible** : Utilise des analogies simples pour expliquer des concepts complexes.
3.  **Direct** : Évite le "remplissage" inutile, chaque phrase doit apporter une valeur.
4.  **Optimiste** : Orienté solution et innovation.

---

## 4. Logo & Assets

- **Version Principale** : Logo sur fond sombre (Slate 900) avec accent Indigo.
- **Transparence** : Toujours utiliser des fichiers SVG pour le CMS Framer.
- **Espacement** : Maintenir un "padding" minimal de 24px autour du logo.

---
> [!NOTE]
> Ces assets seront intégrés directement dans les variables globales de Framer via le `field-mapping.json`.
