# 🌌 Projet Aethera - Guide de Lancement

Bienvenue dans l'espace de travail **Aethera**. Ce projet suit les protocoles d'Antigravité pour automatiser la production de contenu.

## 🎯 Objectifs du Projet
- Automatisation du workflow de contenu pour Aethera.
- Intégration Framer complète (CMS, Blog, Landing Page).
- Scoring IA basé sur la voix de marque spécifique à Aethera.

## 📂 Structure du Projet
- `aethera/PLAN-DE-MATCH.md` : Suivi des tâches en cours.
- `aethera/BRAND-VOICE.md` : Définition des prompts et du ton.
- `aethera/CONFIG.md` : Paramètres techniques (Drive ID, Framer Webhooks).
