# 🛠️ Aethera - Configuration Technique Framer

Guide pour Xavier pour la mise en place de l'instance Framer spécifique à Aethera.

## 1. Instance Framer
- Créer un nouveau projet : `Aethera - Official Site`.
- Domaine : `aethera-site.framer.website` (ou domaine personnalisé si disponible).

## 2. Structure CMS Requise
| Nom du Champ | Type | Description |
| :--- | :--- | :--- |
| **Title** | Plain Text | Titre de l'article ou de la vidéo |
| **Pillar** | Option | Catégorie (Sales, Leadership, etc.) |
| **Main Image** | Image | Couverture visuelle |
| **Content Body** | Formatted Text | La caption générée par l'IA |
| **Video Link** | Link | Lien vers le contenu source (Drive/YouTube) |
| **Aethera Score** | Number | Score de qualité (1-10) |

## 3. Webhooks & Automatisation
- Les données seront envoyées via Content OS vers cette instance.
- Nécessite l'intégration de "Framer CMS API" une fois disponible.
