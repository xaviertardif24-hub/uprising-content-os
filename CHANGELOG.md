# Changelog

All notable changes to this project will be documented in this file.

## [1.8.0] - 2026-03-10

### Added

- **Internationalization (i18n)**: Comprehensive support for English and French across the entire application.
- **Backendless Demo Mode**: Enhanced Zustand store with LocalStorage persistence for projects, tasks, and media feedback.
- **Clipflow MVP**:
  - Linear workflow tracking (Ideation -> Publication).
  - Media Bank with hover previews and categorization.
  - Content Creator specialized task view.
  - Professional Media Review interface with persistent timestamped feedback.
- **Interactive Features**: Ability to add new projects and tasks directly from the UI in demo mode.

### Fixed

- Navigation breadcrumbs and tooltip translations.
- Toast notifications localization.

## [1.6.0] - 2026-03-09

### Added

- Royal AI Chatbot integration.
- Immersive Settings modal.
- Team Spaces library view.

## [1.5.0] - 2026-03-08

### Added

- Search system with history.
- French language initial support.
- Project updates page.
